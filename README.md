# Farsight 千里眼：20MB 的桌面管理工具，自备服务器、装好即用

> 一台服务器 + 一个 20MB 客户端，把设备运维这件事做简单。

Farsight 是一款轻量化的桌面管理工具，适用于三种场景：企业终端运维、家庭上网习惯管理、中小企业的日常设备看护。

**所有能力都建立在「设备归你所有、或已获得明确授权」的前提之上。**

---

## 轻到几乎感觉不到

- 客户端安装包 **不到 20MB**
- 运行时内存 **< 70MB**，CPU 占用常年个位数
- 不拖开机、不卡设计软件、不影响游戏帧率

老电脑、门店收银机、工控机都装得下。

## 部署只要一条服务器

系统分 **server 端** 和 **agent 端**。服务端装在一台服务器上（云主机、公司机房、家里的小主机都行），客户端装在被管理的电脑上，填个地址就上线。

三端代码独立，按需改造；数据落在你自己的存储里。

### 一屏看全所有主机

![主机列表](https://img2024.cnblogs.com/blog/1964999/202611/1964999-20261125004540696-1144447674.png)

在线状态、系统版本、CPU、内存、当前窗口、连接方式（公网 / P2P）全在一张卡片里。直播、录制、观看、编辑都是一键。

### 点进任意一台，就是完整控制台

![控制面板](https://img2024.cnblogs.com/blog/1964999/202611/1964999-20261125004608733-892761371.png)

基础信息、功能配置、屏幕截图、屏幕录制、设备输入、活动日志、运行软件、浏览器记录、文件管理、文件删除、Agent 日志——十一个标签页，收在一个页面里。

### 采集什么，由你决定

![功能配置](https://img2024.cnblogs.com/blog/1964999/202611/1964999-20261125004802585-979956319.png)

录屏、键盘、剪切板、屏幕截图、文件删除备份，每一项都能单独开关；备份保留天数、单文件大小上限也能细调。保存后即时下发，不重启。

家庭场景可以只开截图和活动日志；企业场景在履行告知义务后，再按需开启完整审计。

### 按键输入：每一次按下都有记录

![设备输入](https://img2024.cnblogs.com/blog/1964999/202611/1964999-20261125004802639-1595332537.png)

核心就一句话：**每一次按下都被记下来**。键盘、剪切板、鼠标三类分开留存，每一条带精确到秒的时间戳，可按时间翻页、按内容搜索。不是「大概输过什么」，而是「这一秒按了哪个键、输入了什么」。

### 用户活动：一台电脑的完整轨迹

![用户活动](https://img2024.cnblogs.com/blog/1964999/202611/1964999-20261125004802622-1602495603.png)

「几点打开了什么、在这个窗口停留了多久、几点离开」按秒串成一条时间线，像行车记录仪一样把这台电脑的一天还原出来。支持关键词搜索和分页。

### 运行软件：当前窗口一目了然

![运行软件](https://img2024.cnblogs.com/blog/1964999/202611/1964999-20261125004802588-837744460.png)

正在使用的程序高亮显示，已打开的窗口按任务栏排列，路径与进程名齐全。

### 浏览器记录：访问轨迹可回溯

![浏览器记录](https://img2024.cnblogs.com/blog/1964999/202611/1964999-20261125004802568-1024562921.png)

网址、页面标题、访问时间、浏览器类型，按天归档。

### 文件管理：远程就是本地

![文件管理](https://img2024.cnblogs.com/blog/1964999/202611/1964999-20261125004802636-889444241.png)

磁盘、桌面、下载、文档一键直达，双击进目录，支持上传下载。

## 使用边界

这类工具涉及设备数据，请在合法合规的前提下使用：

- 仅在自己拥有、或已获得明确授权的设备上安装
- 企业场景需事先告知使用范围与目的，并取得员工同意
- 家庭场景建议与家人明确约定使用规则
- 数据存放在自己可控的服务器上，遵循最小必要原则，设定留存期限并到期清理

工具的价值在于让操作可追溯、让问题有据可查，而不是制造压力。
